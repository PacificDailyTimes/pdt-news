# Packages

- `pdt` — built binary (Arch PKGBUILD, Debian, RPM)
- `pdt-git` — build from GitHub master (`git clone` in the recipe; copy PKGBUILD and set `pkgname=pdt-git`)
- `pdt-tar` — from the release tarball without a package index

Post-install is **passwordless**. The admin is created at `/install` in the browser.
